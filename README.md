# 3D FlipBook PDF Hosting

This repository hosts PDF files for the 3D FlipBook viewer on [stellarcresco.com](https://stellarcresco.com).

## Structure

- `/pdfs` - Contains all PDF files served to the flipbook viewer

## How to Add PDFs

1. Navigate to the `/pdfs` folder in this repository
2. Click "Add file" → "Upload files"
3. Select your PDF file(s)
4. Commit the changes to the `main` branch
5. The PDF will be accessible at: `https://Batticus1.github.io/flipbook/pdfs/your-file-name.pdf`

## GitHub Pages Configuration

PDFs are served via GitHub Pages from the root of the repository. All files in this repo are publicly accessible.

## URL Format

Reference PDFs in your Wix flipbook viewer using:
```
https://Batticus1.github.io/flipbook/pdfs/filename.pdf
```

Replace `filename.pdf` with your actual PDF name.
